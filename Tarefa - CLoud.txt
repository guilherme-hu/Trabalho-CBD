Cloud Computing & Cloud Storages

O objeto desta tarefa é realizar um estudo sobre um dentre os principais serviços de nuvens do mercado (Cloud Provider) : AWS, Azure, Google Cloud, ou Oracle Cloud. Abaixo segue um roteiro que pode auxiliar nessas pesquisas:

1.         Conceito de Cloud Computing e Definição de Cloud Storage

2.         Modelos de serviço: IaaS, PaaS, SaaS, DBaaS, DWaaS

3.         Definição dos tipos de nuvem (pública, privada, híbrida)

4.         Discussão sobre as características de acessibilidade, disponibilidade, latência, escalabilidade, confiabilidade, segurança, custo etc.

5.         Sendo a escolha a AWS (Grupos 3 e 7), mencionar:

a)      Computação: EC2

b)      Armazenamento: S3 (armazenamento de objetos), EBS, Glacier

c)      Banco de dados: RDS (DBaaS para MySQL, PostgreSQL, Oracle, SQL Server), Aurora, DynamoDB, Redshift (DWaaS)

6.         Sendo a escolha a Azure (Grupos 4 e 5), mencionar:

a)      Computação: Azure Virtual Machines

b)      Armazenamento: Azure Blob Storage, Disk, File Storage

c)      Banco de dados: Azure SQL Database (DBaaS), Cosmos DB, PostgreSQL, MySQL, Azure Synapse Analytics (DWaaS)

7.         Sendo a escolha a Google Clould Platform (GCP) (Grupos 1 e 2), mencionar:

a)      Computação: Compute Engine

b)      Armazenamento: Cloud Storage, Persistent Disk

c)      Banco de dados: Cloud SQL (DBaaS), Firestore, Bigtable, BigQuery (DWaaS)

8.         Sendo a escolha a Oracle Cloud Infrastructure (OCI) (Grupo 6), mencionar:

a)      Computação: Compute

b)      Armazenamento: Object Storage, Block Volumes

c)      Banco de dados: Oracle Autonomous DB (DBaaS), MySQL HeatWave, Oracle Analytics Cloud (DWaaS)

9.      Qual o custo, vantagens e desvantagens para armazenar e processar uma base de dados de 3.5 PetaBytes?

A maioria das informações atualizadas sobre esse assunto podem ser encontradas em livros não listados como referências dessa disciplina. Em destaque temos o livro do T. Erl, R. Puttini e Z Mahmood (Cloud Computing: Concepts, Technology & Architecture), que oferece uma visão completa desse tema, e o livro "open access" da Huawei Technologies (Cloud Computing Technology, 2023). Há um material introdutório online da Beatriz Oliveira e Mariana Carvalho (Guia da Computação em Nuvem) em português no site (https://archive.org/details/guia-da-computacao-em-nuvem). Outras informações podem ser levantadas nos sites dos provedores de nuvem mencionados (Cloud Providers) e através de assistentes de IA (recomendo o uso crítico).

Nas referências desta disciplina, esse assunto é abordado nos finais das seções 1.9 (History of Database Systems, Years 2010) e 12.2 (Storage Interfaces), e na seção 20.7 do livro do Silberschatz, Korth e Sudarshan (Sistema de Banco de Dados, 7a edição). Já no livro do Elmasri e Navathe (Sistemas de Banco de Dados, 7a edição) esse assunto é mencionado nas aberturas dos Capítulos 1 e 2 e nas seções 25.6.2 (Big Data in Cloud Computing) e 25.6.3. Nas referências complementares este assunto é discutido na seção 1.6.5 do livro do M.T. Özsu e P. Valduriez (Principles of Distributed Database Systems).
